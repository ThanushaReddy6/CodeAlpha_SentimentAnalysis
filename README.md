# 💬 Sentiment Analysis — Amazon Reviews
## CodeAlpha Data Analytics Internship | Task 4

## 📌 Project Overview
Performed Sentiment Analysis on Amazon App Reviews
to classify them as Positive, Negative or Neutral
using VADER Sentiment Analyzer in Google Colab.

## 🛠️ Tools & Libraries Used
- Python 3
- Pandas
- VADER Sentiment Analyzer
- Matplotlib
- Seaborn
- WordCloud
- Google Colab

## 📈 Visualizations Created
1. Sentiment Distribution — Bar Chart
2. Sentiment Percentage — Pie Chart
3. Sentiment Score Distribution — Histogram
4. Positive Reviews — Word Cloud
5. Negative Reviews — Word Cloud
6. Average Score by Category — Bar Chart

## 🔍 Key Findings
- Majority of Amazon reviews are Positive
- VADER compound score ranges from -1 to +1
- Word clouds reveal common words per sentiment
- Clear score difference between categories
